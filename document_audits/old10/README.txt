최종 결과보고서 v1.1 - 한글 표시 수정본

제출·열람: engine_final_report_v1_1.pdf
편집: engine_final_report_v1_1.docx

수정한 사항
- 4쪽 시스템 구성도와 7쪽 모델 변환도를 한글 지원 글꼴로 재작성했습니다.
- 본문의 저장 후 PLC 결과 전달 흐름에 맞춰 구성도의 화살표를 정리했습니다.
- 페이지 나눔과 이력 화면의 표시 크기를 조정하여 불필요한 넘침 페이지를 없앴습니다.
- 페이지 번호를 추가했습니다. 최종 PDF는 15쪽입니다.
- 다운로드용 파일 이름은 영문으로 정리했습니다.

유지한 사항
- 문서 버전 표시를 제외한 Word 본문·표의 모든 텍스트를 보존했습니다.
- 모델 지표, 시험 수치, 사진 원본, 성능 그래프와 웹 화면의 이미지 바이트는 변경하지 않았습니다.
- 새로운 학습, 모델 평가, 장비 시험 또는 GitHub 수정은 수행하지 않았습니다.

검증
- Word를 PDF와 15개 페이지 이미지로 변환한 뒤 전체 페이지를 확인했습니다.
- PDF에 사용된 한글 글꼴이 포함되어 있는지 확인했습니다.
- 파일 해시와 ZIP CRC를 확인했습니다.

이 ZIP은 최종 결과보고서 수정본 묶음이며, 프로젝트의 모든 원본 증빙 ZIP을 포함하는 전체 제출 패키지는 아닙니다.
