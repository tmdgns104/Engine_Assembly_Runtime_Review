## 수정한 내용
- 6절 Benchmark 산식에 누락된 실행당 5회 순환을 반영했습니다.
  4조건 × 3회 독립 실행 × 72장 × 5회 순환 = 4,320개 지연시간 기록입니다.
- 2절 처리 순서를 새 영상·AI 판정 → 저장 완료 확인 → PLC Result/Done → 이력 조회로 명확하게 정리했습니다.
- 3절에 PLC 결과 전송은 같은 요청의 저장·완료 조건을 충족해야 한다는 설명을 보완했습니다.
- 실물시험은 4c4b, 후속 UI 운영본은 32c4라는 근거 범위를 함께 적었습니다.
- 6절 성공 기준표를 3쪽 안에 모두 배치하고, A4·셀 여백·한글 글꼴·쪽번호를 정리했습니다.
- 근거 PDF 링크는 Engine_Assembly_Runtime_Review, 실행·학습 코드 링크는 Engine_Assembly_Defect_Inspector로 구분했습니다.
