## 핵심 결과

동일 Jetson Orin Nano, 기존 25W, E03 개발 검증 72장, batch 1, 고정640 입력으로 비교했습니다.
4조건 × 3반복, 각 360구간 = 4,320개 시간 기록입니다. 4,320개의 서로 다른 제품이나 사진을 의미하지 않습니다.

| 항목 | M1 부품 검출 | M2 엔진 전체 검출 |
|---|---|---|
| 평균 지연 PT → TRT | 29.313 → 29.022 ms | 29.480 → 30.266 ms |
| 평균 지연 변화 | 약 0.99% 감소 | 약 2.67% 증가 |
| 처리량 PT → TRT | 34.06 → 34.41 image/s | 33.87 → 33.00 image/s |
| 측정 중 RSS 관측 최대 PT → TRT | 1250.5 → 636.9 MiB | 1263.8 → 649.7 MiB |
| 위 RSS 관측 최대 감소율 | 약 49.07% | 약 48.59% |
| 고정 confidence0.25 / 정답IoU0.50 | 양쪽 TP192, FP0, FN0 | 양쪽 TP72, FP0, FN0 |
| mAP50–95 PT → TRT (cutoff0.001) | 0.639911 → 0.640873 | 0.836717 → 0.836629 |

이번 전처리·후처리 포함 측정에서는 큰 속도 향상이 확인되지 않았습니다.
메모리 감소는 프레임워크·라이브러리 비용을 포함한 프로세스 RSS의 관측 최대 비교입니다.
GPU 전용 메모리 절감률이나 모델 파일 용량 감소로 바꾸어 설명하지 않습니다.

## 검증 파일 구분

- `M1_M2_benchmark_measurement_verification.json`: 원본 ZIP 안 `verification.json`의 동일 바이트 복사본. 이번 측정·참조·복구의 Codex 검증입니다.
- `M1_M2_benchmark_evidence_v001_zip_verification.json`: Codex가 작성한 원본 ZIP 크기·해시·CRC·파일집합 검증입니다.
- `reviewer_audit.json`: 보고서 작성 단계의 별도 확인 결과입니다. ZIP 해시/파일, 저장된 시간·메모리 재집계, 저장된 예측의 고정IoU TP/FP/FN, AP 배열·평균 계산 등을 대조했습니다. 새 GPU 추론 또는 Ultralytics 전체 평가기 재실행이 아닙니다.
- `figure_provenance.json`: 보고서의 정답/PT/TRT 비교 그림에 사용한 원본 위치와 동일 영역 확대 기록입니다. 원본 증빙 ZIP은 변경하지 않았습니다.
- `submission_manifest.json`: 이 제출 묶음 자체의 파일별 SHA-256과 크기입니다. 자기 자신은 목록에서 제외합니다.

별도 업로드된 `verification(1).json`은 과거 자산 목록 조사 검증이므로 이 제출 묶음에 넣지 않았습니다. 이번 측정 완료를 해당 과거 파일로 입증하지 않습니다.

## 범위와 한계

이 보고서는 저장된 엔진 사진을 실제 Jetson에서 처리한 개발 검증 Benchmark입니다.
실물 엔진 투입, 카메라 촬영FPS, 자세 정렬·슬롯·3프레임 판정·DB·PLC 전 과정의 시험이 아닙니다.
보호된 E04/B04는 사용하지 않았습니다. 전체 모델 파일과 전체 학습·검증 이미지도 이 Benchmark ZIP에 중복 포함하지 않았습니다.
전체 사진·라벨은 기존 `M1_M2_dataset_evidence_v002`와 별도로 함께 제출해야 하며, 이 묶음만으로 원본 모델·전체 데이터가 생기지는 않습니다.

mAP용 cutoff0.001에서는 면적0 후보를 IoU0의 FP 후보로 보존하는 평가용 후처리를 두 백엔드에 동일 적용했습니다.
운영코드 변경과 구분했고, 최초 중단 결과는 보존했습니다. 보고서 12쪽을 참고합니다.

장치 복구는 첨부 당시 서비스 실행·새 카메라 영상·실제 IPC 준비 신호 관측에 근거합니다.
원자료의 ready=false / AREA_REFERENCE_INVALID·UNKNOWN 등 잔존 표시를 보고서 13쪽에 함께 기재했습니다.
복구 후 실물 제품 검사까지 다시 통과한 것으로 확대하지 않습니다. 보고서 작성 중 장치에 재접속하지 않았습니다.

원본 수치·기록·실패 이력은 보존했고 새 측정·학습·추론·배포·PLC 운전은 수행하지 않았습니다.
